# 뒹굴신 입영작 1000문장

개인용 오프라인 안드로이드 영어 학습 앱. 현재 버전은 **0.4.2**입니다.

## 기능

- 카테고리 선정, 듣고 익히기, 선별, 묶음 학습, 진도 체크, 설정
- 문장별 네 발화, 첫 발화만 듣기, 반복·속도·싱크 조정
- 화면을 꺼도 재생하는 Media3 백그라운드 재생
- 듣기/말하기 기준을 분리한 나옴·머뭇거림·못 떠올림 선별
- 5·10·20문장 묶음의 듣기·받아쓰기·꺼내기/영작
- 로컬 SQLite 학습 기록과 중단 지점 저장

### 0.4.2 변경

- 홈의 문장 검색에서 영어 단어·표현·문장 또는 한국어 뜻을 입력합니다.
- 현재 카테고리와 관계없이 전체 1,000문장을 검색합니다.
- 영어는 대소문자와 여분 공백을 무시하고, 이어진 표현을 찾습니다. 정규식이나 의미 유사도 검색은 아닙니다.
- 검색 결과로 5·10·20문장 묶음을 만들고 남은 검색 결과를 다음 묶음으로 이어갑니다.
- 검색 묶음과 남은 문장 목록을 저장해 앱 재시작 후에도 이어갈 수 있습니다.
- 진행 중인 묶음을 교체할 때 안내하며, 기존 카테고리와 학습 기록은 유지합니다.

### 0.4.1 변경

- 이전·다음 문장으로 즉시 이동하며 재생/일시정지 상태를 유지합니다.
- 선별의 다시 듣기 버튼을 제거했습니다.
- 선별 및 묶음 학습 원문 확인의 원형 재생 버튼은 발화 1→2→3→4→1 순환입니다.
- 문장별 발화 순서를 저장하며 발화 번호와 발음 표기를 함께 갱신합니다.

## 학습 자료

이 공개 저장소에는 음성, PDF 원문, PDF 기반 학습 데이터, 개인 학습 기록, 서명 키를 포함하지 않습니다.
앱 전체 기능을 실행하려면 별도로 보관한 아래 파일을 `app/src/main/assets/`에 복사해야 합니다.

- `catalog.json`: 문장, 뜻, 발음 표기, 해설, 카테고리와 발화별 시간
- `full1000.m4a`: 해당 카탈로그와 시간이 일치하는 음성

파일이 없으면 빌드는 가능하지만 전체 학습 기능은 사용할 수 없습니다. 저장소만으로 콘텐츠가 자동 다운로드되지 않습니다.
기존 로컬 프로젝트와 APK에는 자료가 그대로 보존되어 있습니다.

## 빌드

JDK 17 이상, Android SDK 35, Gradle 8.10.2를 사용합니다. 최소 Android 8(API 26), target SDK 35입니다.
Android Studio에서 열거나, SDK 경로를 `local.properties`의 `sdk.dir`로 지정한 뒤 실행합니다.

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

기존 설치에 업데이트하려면 **기존 앱과 같은 서명 키**로 빌드해야 합니다.
다른 PC에서 자동 생성된 debug 키로 빌드하면 기존 앱에 업데이트할 수 없습니다.
기존 앱을 삭제하거나 데이터를 초기화하지 마세요. 기존 키는 로컬에서 별도 보관합니다.

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 구조

- `LearningActivity`: 홈, 검색, 카테고리, 선별, 묶음 학습, 진도
- `SentenceSearch`: 영어·한국어 표현 검색과 입력 정규화
- `MainActivity`: 연속 듣기와 설정
- `PlaybackService`: 화면 꺼짐 재생, 임시 발화 듣기와 기존 재생 위치 복원
- `Catalog`: 로컬 콘텐츠와 싱크
- `StudyStore`: 학습 기록과 통계

기존 설정은 study preferences, 새 학습 진행은 learning preferences와 learning.db에 저장합니다.
연습 결과가 선별 상태를 자동으로 변경하지 않습니다. 영작은 의미 기반 자동 채점을 하지 않습니다.
학습 조건 통계는 관찰 기록이며 최적 학습 시간이나 인과관계를 단정하지 않습니다.

## 검증

0.4.2 빌드 및 lint를 통과했습니다. 검색 로직 10개 사례와 에뮬레이터에서 검색 결과,
카테고리 유지, 결과만 포함한 묶음, 앱 재시작 복원, 중복 없는 다음 묶음 연결을 확인했습니다.
Android 16 기기에 0.4.2를 삭제 없이 업데이트했고 기존 설정과 학습 DB 보존을 확인했습니다.
음성·자막·싱크 데이터는 0.4.1과 동일합니다. 결과는 `tests/0.4.2-results.json`에 있습니다.

학습 자료 없이 실행 가능한 검색 로직 테스트(JDK 필요):

```powershell
javac -encoding UTF-8 -d tests/build app/src/main/java/kr/local/listenloop/SentenceSearch.java tests/SearchCheck.java
java -cp tests/build SearchCheck
```


0.4.1 빌드 및 lint 통과(오류 0). 에뮬레이터에서 재생/일시정지 문장 이동,
발화 1→2→3→4→1 순환, 원문 확인 후 순환 유지, 묶음 듣기 버튼을 확인했습니다.
Android 16 실제 기기에 삭제 없이 업데이트하고 설정·학습 DB 보존을 확인했습니다.
전체 4,000개 발화의 청취 검수를 새로 수행한 것은 아닙니다.

`tests/0.4.1-ui-results.json`에 해당 검증 결과가 있습니다.
기존 instrumentation 테스트는 별도 learning_test 데이터베이스와 preferences를 사용합니다.
